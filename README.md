# koyhl.github.io

Public pages for koyhl apps, served by GitHub Pages at https://koyhl.github.io.

- `/privacy/blockpuzzle/`: Block Puzzle privacy policy
- `/terms/blockpuzzle/`: Block Puzzle terms of service (linked from Play Console as the trader's terms)

For a new app, copy `privacy/blockpuzzle/` to `privacy/<app>/` and `terms/blockpuzzle/` to `terms/<app>/`, put its icon in `assets/games/<app>.png`,
edit the page, and add the app to `index.html`. Every page shares `assets/site.css`
and `assets/site.js`; studio brand images live in `assets/brand/`.

`app-ads.txt` lists the ad sellers authorised for every app; Google Play links it through the
developer website (https://koyhl.github.io). Append the lines each new ad network gives you.
