# koyhl.github.io

Public pages for koyhl apps, served by GitHub Pages at https://koyhl.github.io.

- `/privacy/blockpuzzle/`: Block Puzzle privacy policy

For a new app, copy `privacy/blockpuzzle/` to `privacy/<app>/`, edit it, and list it in `index.html`.

`app-ads.txt` lists the ad sellers authorised for every app; Google Play links it through the
developer website (https://koyhl.github.io). Append the lines each new ad network gives you.
